# 关于迅树 MD

迅树 MD 是围绕 Markdown 笔记、首页文件树、局域网同步与多格式附件构建的个人资料管理工具。

希望将日常记录、工作文档和学习资料整理成由用户自行保存和管理的文件，而不是将内容限制在单一页面里。

## 产品方向

- **局域网同步**：帮助用户在自己的设备之间管理与同步数据；具体支持的平台与功能以实际发布版本为准。
- **首页文件树**：便于分类和管理多篇笔记。
- **Super MarkDown**：以 Markdown 为基础拓展更多内容类型。Office 文档仅渲染查看，不能宣传为 Office 原格式编辑。
