# 局域网同步

迅树 MD 的局域网同步目标是让笔记文件留在用户自己的设备上，通过局域网进行 P2P 数据传输。

## 基本原则

- 由用户**主动触发**文件同步；发现设备不代表自动传输文件。
- 设备发现、配对、可信连接确认和实际文件同步是不同步骤。
- 按同步差异预览和用户确认处理文件变更。

## 设备使用

目标覆盖不同屏幕尺寸和设备系统。实际已支持的操作系统组合、同步兼容性与验收结果应在发布后填写。

## 123 云盘

123 云盘只规划用于**原生应用内部的云端数据同步**，与局域网 P2P 同步是独立能力，不提供安装包公开分享下载。相关功能未通过开发验收前，不列为已经发布的同步方式。
