# 创建第一篇笔记

迅树 MD 使用 Markdown 作为笔记的主要文字格式。

## 建立资料目录

使用首页文件树管理文件夹和笔记。实际入口、命名规则与路径约束以正式发布的应用为准。

## 编写内容

可使用标题、列表、待办列表等 Markdown 语法组织笔记，也可以在支持的版本中插入多媒体内容。

## 保存笔记

迅树 MD 的原生应用遵循用户主动保存的产品设计。需要保存时，请按软件当前界面提供的保存方式操作。
