# 常见问题（FAQ）

## 官网的安装包从哪里下载？

前往 [软件下载](/download/) 页面，正式安装包通过 GitHub Releases 获取。没有 123 云盘备用下载。

## 在线体验会保存我的笔记吗？

现有 Web Mock 的产品设计是**仅内存模拟**：刷新或重新打开会恢复预置演示数据，不读写用户真实文件。

## 不同设备之间会自动同步吗？

迅树 MD 现有局域网 P2P 同步设计要求由用户手动触发文件传输，设备发现与配对状态确认不等同于自动同步文件。

## 123 云盘是下载渠道吗？

不是。123 云盘只作为未来原生应用内云同步的功能规划，不用于安装包分发。

## 能直接编辑 Word、Excel、PPT 吗？

官网目前将 Office 附件描述为**仅渲染查看**，不承诺原格式编辑能力。支持范围以最终发布版本的验收结果为准。

## 如何查看开源致谢？

通过网站顶部「关于」菜单进入 [开源致谢](/acknowledgements/) 与 [第三方许可证](/licenses/)。
